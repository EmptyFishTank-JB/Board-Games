# Board Games — Add-On Rules

Custom add-on/expansion rules for existing board games, written up for sale on Etsy.

## Structure

Each game gets its own folder at the root, named after the game (lowercase, hyphenated):

```
<game-name>/
  rules.md       # the add-on rules themselves
  notes.md       # optional: design notes, playtesting feedback, Etsy listing draft
  assets/        # optional: images, diagrams, card art references
```

See `_template/` for a starting point when adding a new game.

## Workflow

1. Copy `_template/` to `<game-name>/`.
2. Draft the rules in `rules.md`.
3. Playtest, iterate, keep notes in `notes.md`.
4. Once finalized, format for print/PDF and list on Etsy.
